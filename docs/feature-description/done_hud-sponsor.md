# Sponsor Customization for HUD GFX

STATUS: Done.

## Goal

- Allow setting custom sponsor assets for the HUD. This includes:
  - Custom Ceremonial Banners background
  - Custom Ceremonial Banners logo
  - Custom Sponsor Loop (add logos at the sponsor loop area, then loop over them at a set period of time)
